# Uma Factor Checker

ウマ娘の因子一覧画像を解析し、設定したS/A/B/Cのスキル要件を何面が満たすか確認するブラウザツールです。

## 開発状況

現在はβ版・公開テスト中です。

- スキル要件チェック: 公開テスト対象
- 代表ウマ娘チェック: 開発中（公開テスト対象外）

## 既知の制限

- OCRのため誤認識が発生する場合があります。要確認項目は元画像を確認して手動補正できます。
- 青・赤因子名が一部「名称未確定」になる場合があります。
- Factor Masterは段階的に拡充中です。未登録の正式因子は「その他の未確定因子」になる場合があります。
- 対応画像は現在サポートしている、ウマ娘1人分の「因子一覧」形式に限られます。
- ページを再読み込みした後の登録画像復元には対応していません。

## dev / pro 環境

ビルド不要。HTTP(S)の `localhost` / `127.0.0.1` / `[::1]` のみdev、その他はproです。
Gitブランチ名やURLパラメータ、localStorageによる環境切替は行いません。

- ローカル検証：featureブランチでリポジトリ直下から `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000/` を開きます。
- main / GitHub Pages：従来どおりmainの静的ファイルを公開します。公開ホストでは自動的にproとなり、Dev UI、デバッグ表・ログコピー、fixture操作は無効です。マージ時のコード削除・設定変更は不要です。
- 環境は配信先で決まります。mainもローカルで開けばdevです。LAN IPやfile://で開いた場合はproです。公開版をローカルで確認する場合は、ループバック以外のホスト名を使用してください。

devの画像登録画面で「テスト画像10枚をセット」を押すと、
`tests/fixtures/factor-images/regression-20260916/` の既存画像を変換せず読み込みます。
既存10枚は拡張子が `.png` ですが実体はJPEGです。ファイル名・内容は変更せず、登録時のMIME型だけ実体に合わせます。
ファイル名は `skill-check-` + 下表 + `.png` です。

| 枠 | ファイル名の中央部分 |
| --- | --- |
| 親A | parent-a-01, parent-a-02 |
| A祖1 | grand-a1-01 |
| A祖2 | grand-a2-01, grand-a2-02 |
| 親B | parent-b-01, parent-b-02 |
| B祖1 | grand-b1-01 |
| B祖2 | grand-b2-01, grand-b2-02 |

全10枚の取得・デコードと通常の `addImages` による登録準備が成功した場合だけ、既存6枠を置換します。
失敗時は既存画像を保持し、解析中は置換しません。セット後は通常の「画像を解析」を押してください。
公開リポジトリ内の画像自体は公開データです。proで無効化するのはアプリのDev操作です。

限定テスト：`node --experimental-vm-modules tests/dev-environment.test.mjs`
