# Uma Factor Checker

ウマ娘の因子一覧画像を解析し、設定したS/A/B/Cのスキル要件を何面が満たすか確認するブラウザツールです。

## 開発状況

現在はβ版・公開テスト中です。

- スキル要件チェック: 公開テスト対象
- 代表ウマ娘チェック: 開発中（公開テスト対象外）

## 既知の制限

- OCRのため誤認識が発生する場合があります。要確認項目は元画像を確認して手動補正できます。
- 青・赤因子名が一部「名称未確定」になる場合があります。
- 低優先度の読み取り結果には、要件外の因子やレース因子なども含まれます。
- 対応画像は現在サポートしている、ウマ娘1人分の「因子一覧」形式に限られます。
- ページを再読み込みした後の登録画像復元には対応していません。
